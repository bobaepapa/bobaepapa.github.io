ScanHook 개인정보 처리방침
기준일: 2026-11-20 / 대상: ScanHook 0.1.0

ScanHook 앱은 개인정보를 개발자 서버로 수집하거나 전송하지 않으며 광고, 분석 SDK, 사용자 추적 기능을 포함하지 않습니다. 앱 계정이나 로그인이 필요하지 않습니다.

카메라는 QR 코드를 읽는 데만 씁니다. 카메라 영상과 사진은 저장하거나 전송하지 않습니다.

API 전송이 켜져 있으면, 읽은 QR 코드의 값을 사용자가 설정에 직접 입력한 주소로 보냅니다. Bearer token 을 입력했다면 함께 보냅니다. 이 주소의 서버는 사용자 또는 사용자의 조직이 정한 것이며, 그 서버가 받은 데이터를 어떻게 다루는지는 해당 서버 운영자의 정책에 따릅니다. 주소가 http:// 로 시작하면 암호화하지 않고 보냅니다. API 전송을 끄면 아무 곳에도 보내지 않습니다.

기기에 저장하는 것: API 주소와 Body 형식, 전송 켜짐 여부, 재인식 대기 시간은 기기 안의 앱 저장 공간에 보관합니다. Bearer token 은 이 기기의 Keychain 에만 보관하며 다른 기기로 옮겨지지 않습니다. 읽은 QR 값과 서버 응답은 화면에 보여 주는 동안만 메모리에 있고, 이력으로 저장하지 않습니다.

API 전송이 꺼진 상태에서 QR 내용을 터치하면, 웹 주소는 기본 브라우저로 열고 그 밖의 글자는 클립보드에 복사합니다.

로컬 네트워크 접근 권한은 같은 네트워크에 있는 서버로 보낼 때만 씁니다.

저장한 설정은 앱을 삭제하면 지워집니다. token 은 설정에서 비우고 저장하면 Keychain 에서 삭제됩니다.

지원 이메일을 보내면 사용자가 제공한 이메일 주소와 문의 내용을 지원에 사용합니다. token 이나 민감한 QR 내용은 보내지 마세요. 이메일 처리는 이용하는 이메일 서비스의 정책에도 따릅니다.

ScanHook Privacy Policy
Reference date: November 20, 2026 / Applies to ScanHook 0.1.0

The ScanHook app does not collect or send personal data to developer-operated servers. It includes no advertising, analytics SDKs, or user tracking. No app account or sign-in is required.

The camera is used only to read QR codes. Camera video and photos are not stored or transmitted.

When API sending is on, the value of a scanned QR code is sent to the address you entered in settings, together with the Bearer token if you entered one. That server is chosen by you or your organization, and how it handles the data it receives is subject to its operator's policies. If the address starts with http://, the data is sent unencrypted. When API sending is off, nothing is sent anywhere.

Stored on your device: the API address and body format, whether sending is on, and the rescan delay are kept in the app's storage on the device. The Bearer token is kept only in this device's Keychain and is not transferred to other devices. Scanned values and server responses are held in memory only while they are shown, and no history is saved.

With API sending off, tapping the QR contents opens a web address in your default browser or copies any other text to the clipboard.

Local network access is used only to reach a server on the same network.

Saved settings are removed when you delete the app. The token is deleted from the Keychain when you clear it in settings and save.

If you email support, your email address and the information you provide are used to respond to your inquiry. Please do not send tokens or sensitive QR contents. Email processing is also subject to the email service provider's policies.
