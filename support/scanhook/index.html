QR 코드만 읽습니다. 바코드와 문자 인식은 지원하지 않습니다. 전송 이력은 저장하지 않습니다.

사용법

ScanHook 0.1.0 기준입니다.

API 설정

  • 오른쪽 위 ⚙︎ 를 눌러 설정을 엽니다.
  • URL: http:// 또는 https:// 로 시작하는 주소를 넣습니다. 사내망 주소도 됩니다. 비워 두면 보내지 않습니다.
  • Bearer token: 넣으면 Authorization: Bearer … 헤더로 보냅니다. 비워 두면 이 헤더를 보내지 않습니다.
  • Body: 바깥 중괄호 없이 JSON 필드만 씁니다. {value} 자리에 읽은 값이 들어가고, 따옴표는 직접 씁니다.
    예: "code":"{value}","gate":"1" → QR 값이 1234 이면 {"code":"1234","gate":"1"} 를 보냅니다.
  • Method 는 POST, Content-Type 은 application/json 으로 고정입니다.
  • 재인식 대기: 결과를 보여 준 뒤 다시 인식할 때까지의 시간입니다(1–60초, 기본 10초).

스캔과 전송

  • QR 을 비추면 삐 소리와 진동이 나고 바로 보냅니다. 인식한 QR 에는 녹색 테두리가 표시됩니다.
  • 결과 창에 상태 코드, 걸린 시간, 서버 응답이 나옵니다. 2xx 는 녹색, 그 밖은 적색입니다.
  • 결과 창을 터치하거나 재인식 대기 시간이 지나면 다시 인식합니다. 같은 QR 이 계속 보이면 다시 보냅니다.
  • 요청은 10초가 지나면 시간 초과로 끊습니다.

QR 내용만 보기

  • 왼쪽 위 API 버튼이나 설정의 API 전송으로 전송을 끕니다. 끄면 QR 내용만 보여 줍니다.
  • 내용을 터치하면 http://·https:// 주소는 기본 브라우저로 열고, 그 밖의 글자는 클립보드에 복사합니다.
  • 다시 켜면 화면에 보이는 QR 을 바로 보냅니다.

No camera view: Allow Camera under ScanHook in iPhone Settings.
"API 설정이 필요합니다" (API setup needed): Tap ⚙︎, enter a URL, and save.
"서버에 연결할 수 없습니다" (cannot connect): Check the address and port, and that the iPhone and the server are on the same network. To reach a server on your local network or the same Wi-Fi, allow Local Network under ScanHook in iPhone Settings.
"시간 초과 (10초)" (timed out): The server did not respond within 10 seconds. Check the server.
401 or 403: Check the Bearer token.
400, or the server cannot read the value: Check that the field name in Body matches what the server expects.
Cannot save: Body must contain {value}, written without outer braces and with the quotes typed in, like "name":"{value}".
No beep: In silent mode only the vibration plays.
The wrong QR code was sent: With several codes in view, the one closest to the center of the screen is sent. Center the code you want.

Only QR codes are read; barcodes and text recognition are not supported. No history of sent values is kept. The app's interface is in Korean in this version.

User Guide

This guide describes ScanHook 0.1.0.

API Settings

  • Tap ⚙︎ at the top right to open settings.
  • URL: An address starting with http:// or https://. Local network addresses work. Leave it empty and nothing is sent.
  • Bearer token: Sent as an Authorization: Bearer … header. Leave it empty to send no such header.
  • Body: JSON fields only, without the outer braces. {value} is replaced with the scanned value; type the quotes yourself.
    Example: "code":"{value}","gate":"1" sends {"code":"1234","gate":"1"} for a QR code containing 1234.
  • The method is always POST and the Content-Type is always application/json.
  • 재인식 대기 (rescan delay): How long the result stays before scanning resumes (1–60 seconds, default 10).

Scanning and Sending

  • Point the camera at a QR code. The app beeps, vibrates, and sends the value right away. The recognized code gets a green outline.
  • The result panel shows the status code, elapsed time, and the server's response. 2xx is green; anything else is red.
  • Tap the result panel, or wait for the rescan delay, to scan again. A code that is still in view is sent again.
  • A request is cut off as timed out after 10 seconds.

Viewing QR Contents Only

  • Turn sending off with the API button at the top left or API 전송 in settings. The app then only shows what the QR code contains.
  • Tap the contents to open an http:// or https:// address in your default browser, or to copy any other text to the clipboard.
  • Turning sending back on sends the code in view right away.
