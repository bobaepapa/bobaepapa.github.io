SpeedCalc 지원
수식 계산기 · macOS 13 이상

문의: bobaepapa@gmail.com
SpeedCalc 버전, macOS 버전, 문제가 발생한 수식과 재현 순서를 알려 주세요. 민감한 계산 정보는 제외해 주세요.

곱셈: * 또는 ×를 직접 입력합니다. 2(3+4)는 지원하지 않습니다.
거듭제곱과 XOR: **는 거듭제곱, ^는 비트 XOR입니다.
선행 0: 010은 8진수 8입니다. 십진수 10은 10으로 입력합니다. 08과 09는 잘못된 8진수 입력입니다.
백분율: %는 나머지입니다. 200의 15%는 200*15/100으로 계산합니다.
각도: 계산 메뉴에서 RAD 또는 DEG를 선택합니다. 역삼각함수도 같은 단위를 사용합니다.
언어: 설정 → 일반 → 화면 모드 아래의 언어에서 시스템 설정 따르기, 한국어, English를 선택합니다.
글꼴: 설치된 기본 목록과 활성 사용자 설치 글꼴을 설정에서 선택합니다. 저장된 글꼴이 없으면 시스템 고정폭으로 대체합니다.
정밀도: ≈는 표시 반올림입니다. 표시 설정은 실제 계산값을 바꾸지 않습니다.
저장 안내: 상태 글자에 마우스를 올리면 원인을 확인할 수 있습니다. ⌘S로 기록을 별도 내보낼 수 있습니다. 저장된 세션을 읽지 못하면 원본을 보존하고 자동 저장을 중지합니다.

계산 기록, 변수, 설정은 로컬에 저장합니다. 기록 지우기는 변수와 최근 결과 참조를 유지합니다.

사용법

SpeedCalc 0.6.0 기준입니다. 앱 안에서는 도움말 → SpeedCalc 사용법에서 같은 내용을 짧게 볼 수 있습니다.

기본 사용

  • 수식을 입력하면 아래 상태 줄에 결과 미리보기가 나옵니다. Enter를 누르면 계산 기록에 추가됩니다.
  • 미리보기는 변수나 ans를 바꾸지 않습니다. 오류가 난 계산도 기존 값을 바꾸지 않습니다.
  • 계산 직후 빈 입력창에 *2처럼 연산자부터 입력하면 ans*2로 이어서 계산합니다. 음수로 새 수식을 시작하려면 Esc를 누른 뒤 -2처럼 입력합니다.
  • radius = 12처럼 변수를 저장합니다. ans는 마지막 결과, ans1–ans9는 그 이전 결과입니다. 기록의 [1]–[9] 표시가 이 번호입니다.

결과와 기록 복사

  • 마지막 결과 복사 (⌘K 또는 ⌘R, 계산 메뉴): 마지막으로 확정한 결과를 숫자만 복사합니다. 현재 출력 진법과 소수점 자리수 설정을 따르며, =, ≈, DEC 표시와 자리 구분 간격은 넣지 않습니다. 결과가 없으면 클립보드를 바꾸지 않습니다.
  • 자동 복사: 설정 → 일반 → “마지막 계산 결과를 클립보드에 자동 복사”를 켜면 계산을 확정하거나 출력 진법을 바꿀 때마다 결과를 복사합니다. 기본값은 꺼짐입니다.
  • 기록에서 골라 복사: 계산 기록의 글자를 마우스로 선택하고 ⌘C를 누릅니다. 화면에 보이는 그대로 복사됩니다. 자리 구분 간격이 들어간 숫자도 입력창에 다시 붙여 넣으면 그대로 계산됩니다. 결과 줄 앞의 =나 ≈는 빼고 숫자만 선택하세요.
  • 이전 수식 복사: ↑로 수식을 불러온 뒤 ⌘A, ⌘C를 누릅니다.
  • 기록 전체 내보내기 (⌘S, 파일 메뉴): 각 계산을 [RAD] 또는 [DEG]와 수식, 결과 줄로 텍스트 파일에 저장합니다. 결과는 현재 출력 진법과 소수점 자리수 설정으로 기록합니다.
  • HEX/BIN 출력에서 정수가 ±(2⁵³−1)를 넘으면 복사되지 않습니다. DEC(F3)로 바꾼 뒤 복사하세요.

진법과 비트 연산

  • 입력: 0x 16진수, 0b 2진수, 0o 또는 앞에 0을 붙인 정수는 8진수입니다. 010은 8이고, 08과 09는 오류입니다.
  • 출력 진법은 입력 해석을 바꾸지 않고 표시만 바꿉니다. 기존 기록과 미리보기도 선택한 진법으로 다시 표시합니다. 소수 결과는 BIN/HEX 선택 중에도 십진수로 표시하고 DEC를 붙입니다.
  • 비트 연산: &/and, |/or, ^/xor, ~, <<, >>. ±(2⁵³−1) 범위의 정수만 받고, 시프트 횟수는 0–63입니다.
  • 거듭제곱은 **입니다. ^는 XOR입니다. %는 나머지이며 백분율이 아닙니다.

함수와 각도

  • 함수: abs, acos, asin, atan, atan2, ceil, cos, cosh, exp, floor, hypot, ln, log, log2, max, min, pow, round, sin, sinh, sqrt, tan, tanh. 상수: pi, π, tau, e, phi.
  • 각도 단위(RAD/DEG)는 계산 메뉴에서 고릅니다. 역삼각함수 결과도 같은 단위를 씁니다. log는 밑이 10, ln은 자연로그입니다.
  • 곱셈은 * 또는 ×를 직접 입력합니다. 2(3+4)는 지원하지 않습니다.

설정

  • 일반: 화면 모드(시스템/라이트/다크), 언어, 자동 복사, 숫자 3자리 구분과 간격, 소수점 아래 최대 자리수.
  • 글꼴: 글꼴 선택, 고정폭 글꼴만 보기, 크기 8–40pt, 기본값 복원.
  • 표시 설정은 화면과 복사 형식만 바꾸며, 실제 계산값과 ans는 바꾸지 않습니다. ≈는 표시할 때 반올림했다는 뜻입니다.

저장

최근 2,000개 계산 기록, 변수, 최근 결과 10개, 각도와 출력 진법을 자동으로 저장하고 다음 실행 때 되살립니다. 파일 → 계산 기록 지우기는 기록만 지우고 변수와 최근 결과 참조는 남깁니다.

SpeedCalc Support
Expression calculator · macOS 13 or later

Contact: bobaepapa@gmail.com
Include your SpeedCalc version, macOS version, the expression and steps to reproduce the issue. Remove sensitive calculation data before sending.

Multiplication: Use * or × explicitly; 2(3+4) is not supported.
Powers and XOR: ** means power; ^ means bitwise XOR.
Leading zero: 010 is octal 8. Use 10 for decimal ten. 08 and 09 are invalid octal input.
Percent: % is remainder, not percentage. For 15% of 200, enter 200*15/100.
Angles: Choose RAD or DEG in Calculation. Inverse trig functions use the same unit.
Language: Settings > General > Language (below Appearance) offers Follow System, 한국어 and English.
Fonts: Installed built-in selections and active user-installed fonts appear in Settings. A missing saved font falls back to system monospaced.
Precision: ≈ indicates display rounding; the stored calculation value is not changed by display settings.
Save warning: Hover over the status text for details. Export History (Command+S) saves a separate copy. If a saved session cannot be read, the original is preserved and auto-save stops.

Calculation history, variables and settings are stored locally. Clearing history keeps variables and recent result references.

User guide

This guide covers SpeedCalc 0.6.0. A shorter version is available in the app under Help → SpeedCalc Help.

Basics

  • Type an expression to see a live preview in the status line. Press Enter to add it to your history.
  • Previews never change variables or ans, and neither does a calculation that fails.
  • Right after a calculation, start with an operator such as *2 to continue with ans*2. To start a new negative expression, press Esc and then type -2.
  • Store variables with radius = 12. ans is the last result and ans1–ans9 are earlier results, matching the [1]–[9] labels in the history.

In Settings, Esc reverts every change made since the window was opened and closes it. ⌘W or the close button keeps your changes.

Copying results and history

  • Copy Last Result (⌘K or ⌘R, Calculation menu): Copies only the number of the last confirmed result, in the current output base and decimal-place setting. =, ≈, DEC and digit-group spacing are left out. If there is no result yet, the clipboard is not changed.
  • Automatic copy: Turn on Settings → General → “Automatically copy the last result” to copy the result after every calculation and output base change. It is off by default.
  • Copy from the history: Select text in the history with the mouse and press ⌘C. Text is copied as shown. Numbers with digit-group spacing can be pasted back into the input as is. Select just the number, without the leading = or ≈.
  • Copy an earlier expression: Recall it with ↑, then press ⌘A and ⌘C.
  • Export the whole history (⌘S, File menu): Saves each calculation as [RAD] or [DEG] with its expression and result line to a text file. Results use the current output base and decimal-place setting.
  • In HEX or BIN, integers beyond ±(2⁵³−1) are not copied. Switch to DEC (F3) first.

Number bases and bitwise operations

  • Input: 0x hexadecimal, 0b binary, 0o or a leading zero for octal. 010 is 8; 08 and 09 are errors.
  • The output base changes only how results are shown, including existing history and the preview. Fractional results are shown in decimal with a DEC label, even in BIN or HEX.
  • Bitwise: &/and, |/or, ^/xor, ~, <<, >>. Integers within ±(2⁵³−1) only; shift counts from 0 to 63.
  • ** is power and ^ is XOR. % is the remainder, not a percentage.

Functions and angles

  • Functions: abs, acos, asin, atan, atan2, ceil, cos, cosh, exp, floor, hypot, ln, log, log2, max, min, pow, round, sin, sinh, sqrt, tan, tanh. Constants: pi, π, tau, e, phi.
  • Choose RAD or DEG in the Calculation menu. Inverse trig functions return the same unit. log is base 10 and ln is the natural log.
  • Type * or × for multiplication; 2(3+4) is not supported.

Settings

  • General: appearance (System, Light, Dark), language, automatic copy, digit grouping and spacing, decimal places.
  • Fonts: font, monospaced-only filter, size from 8 to 40 pt, restore defaults.
  • Display settings change only how numbers are shown and copied, never the stored values or ans. ≈ means the shown value was rounded.

Saving

The last 2,000 calculations, variables, the 10 most recent results, the angle unit and the output base are saved automatically and restored on the next launch. File → Clear History removes only the history and keeps variables and recent result references.
